Paste this as the welcome post in GitHub Discussions for the tester repository.

Welcome. This is the 0.1.0-beta of ERIC (Engineered Runtime Interface & Control) and Control Canvas.

ERIC v0.1.1 is BETA software and must only be used with hardware for testing purposes under safe conditions — not for live production, life-safety, or equipment-protection use. It is provided AS IS with no warranty (AGPL-3.0).

Start with TESTING.md and the manual page Getting started for testers. The manual is also served at `/docs` on a running gateway.

Use a discussion to ask how something works. Use an issue when something broke (attach a log with passwords removed), when you want a feature, or when you have finished the first-hour survey.

Nick Hepburn is the maintainer.
