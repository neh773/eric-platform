# The gateway

The gateway is the service that holds tags, projects, history, alarms, and the screens people use. One gateway serves the admin pages, Control Canvas, and the live HMI.

## What you do here

- **Overview** shows whether the gateway is healthy, how busy it is, and the deployment mode.
- **Gateway Settings** holds the system name and the project a new session opens.
- **Modules** installs and removes optional pieces.
- **Backups** takes a copy of the configuration and puts it back.
- **Logs** and **Diagnostics** are where you look when something is slow or a connection is down.
- **[Event streams](../event-streams/)** move a tag change, a Kafka message, or a posted event through a filter and into handlers.

Later pages in this section walk through each of those tasks with the fields on the screen.
