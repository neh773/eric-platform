# Script builder

The script builder writes a common event script so you do not have to type it. It sits under a component event's script in Control Canvas.

1. Select the component and open the event.
2. Under **Script builder**, choose a handler: navigate to a page, navigate to a view, write a tag, or run a named query.
3. Fill the page, view, tag, or query, and any parameters.
4. Click **Add to script**. The text is added to the script, which you can still edit.

The handler list uses the full width of the panel so the names stay readable.

## Dropping a component

Dragging a component onto the canvas, or dropping a tag so the view's drop rule creates a component, saves that component's default settings with it. A tag dropped on a component that is missing those defaults fills them in and keeps any value you already set. The binding is added on top of those settings.
