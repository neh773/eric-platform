Known bugs (0.1.1-beta)

This is the list of open defects found while testing ERIC 0.1.1-beta. It is not a promise that any item will be fixed in a particular release. Features that were never started are on Future features and wishlist, not here.

Check this list before you open a bug report. If the problem is already listed, you do not need a new issue unless you have new information (for example a different operating system or a clearer way to reproduce it). To report a new bug, go to Issues → New issue → Bug report on the public repository. Remove passwords and plant addresses from logs and screenshots.

TitleAreaWhat happensWorkaroundStatus
UDT member initial value coerces on each keystrokeGateway adminTyping an Initial value for a UDT member is converted to the member's data type after every keystroke. For a Boolean, true becomes false; only 1 is accepted. For a decimal, a value such as 95.5 becomes 955.For a Boolean, enter 1 or 0. There is no reliable way to type a fractional value in that field.Open
Expression binding without the gateway name is emptyControl Canvas designerA binding written as {[default]path} resolves to null.Write {[gw][default]path}, with the gateway name in front.Open
No control for a view's width or heightControl Canvas designerA view is fixed at 680×360. There is no form to change the size.Use percent mode so components scale with the session.Open
Style CSS rejects custom propertiesControl Canvas designerA style that uses CSS custom properties is rejected.Use ordinary CSS properties.Open
Indicator has no blink or flash optionControl Canvas designerThe indicator component cannot be set to blink or flash.None.Open
Logic editor right pane overflows and clips valuesLogic/PLCIn the Logic editor right pane, the UDT members table overflows and scrolls horizontally; watch table rows are about 70 px tall and values are cut off; the Programs panel inputs overflow; and inline online values are clipped at narrow widths.Widen the pane where you can.Open
Online values show only the first variable of a multi-variable declarationLogic/PLCIn Logic online mode, a declaration with several variables on one line shows the live value for the first variable only.Declare one variable per line.Open
Expression label shows Uncertain for an empty stringHMI runtimeAn expression label whose value is an empty string shows an Uncertain: initial value overlay.Turn the overlay off (opt out).Open
Alarm status table filters take most of the heightAlarmsFilter controls on the alarm status table use most of the table height, leaving little room for rows.None.Open
Alarm display path is longAlarmsThe alarm display path includes the member and the alarm name, so the path is long.None.Open
Windows PLC scan jitter can latch the overrun watchdogLogic/PLCOn Windows, scan jitter of about 50 ms has been seen on a virtual machine. At a fast scan rate this can trip the overrun watchdog and latch the program. New programs default to a 100 ms period and 10 consecutive overruns.Use a 100 ms scan period (the default), or run the PLC on Linux. Scan times under 100 ms are difficult on Windows.Open
PLC program does not resume after a gateway restartLogic/PLCA program that was running comes back stopped after the gateway restarts.Choose Compile and deploy again.Open
Drivers may stay Not Started after a backup restoreDevicesAfter a restore, some devices and connections have shown Not Started until the gateway was restarted. A later test did not reproduce it.Restart the gateway after a restore.Open
No force inside function block instances in online modeLogic/PLCOnline mode can force mapped I/O only. You cannot force a member of a function block instance, for example a timer input.Force the mapped I/O instead, when that is enough.Open
Show view does not update the browser addressControl Canvas designerSwitching views leaves the previous view in the address bar, so a reload or a shared link opens the wrong view.After a reload, open the view you want again.Open
History queries show empty minutes as blank rowsHistorianMinutes before recording started appear as blank rows with 0 samples, instead of being left out or marked as no data.Ignore rows with 0 samples, or start the query after recording began.Open
Stray Diagnostics label on UDT member rowsGateway adminThe UDT instance member list shows an extra Diagnostics label on member rows. Cosmetic only.None needed.Open
No in-app gateway restartGateway adminThis beta has no Restart button on the admin page. A launcher-started gateway that was stopped from the UI did not come back.Stop ERIC and start it again: the Windows service, or the Linux launcher.Open
Windows: HTTPS certificate file can stay lockedGateway adminAfter the TLS listener stops, https/server.crt can stay locked on Windows. A backup restore or wipe that replaces https/ can fail until the gateway restarts.Restart the gateway, then retry the restore or wipe.Open
Large tag imports are slowGateway adminWriting 100,000 tags in one batch took about 75 seconds on a 4-core test laptop, against a 20-second target.Import in smaller batches, or allow more time.Open
Windows uninstall or upgrade asks for a reboot while the service is runningOtherUninstalling or upgrading while the ERIC Gateway service is still running asks for a reboot. The installer does not stop the gateway service or eric-plc before it replaces files.Stop the ERIC Gateway service and eric-plc before you uninstall or upgrade.Open
Restarting the ERIC Gateway service needs an elevated promptOtherRestarting the service from a non-elevated prompt fails with Cannot open ERIC Gateway service.Use an elevated prompt, or Services (services.msc) with an administrator account.Open
Linux resource split Preview change will not clear, and Revert needs a root helperLogic/PLCOn the PLC / ERIC resource split page, after Preview the pending isolcpus change stays even after a reload. Revert says "The root helper is not configured". The change is not applied and the gateway keeps running.Do not use Preview, Apply or Revert on this page unless a root helper is configured.Open
UDT instance name pattern requires {n} even for one instanceGateway adminCreating UDT instances requires {n} in the name pattern, even when you are creating only one instance.Include {n} in the pattern, for example Station_{n}.Open
UDT member tags cannot be written from the tag browserGateway adminA UDT member tag cannot be written from the tag browser.Write the value from an HMI control or from Logic.Open
Linear scaling clamps by default and flags engineering units exceededGateway adminLinear scaling clamps the value to the engineering range by default and silently flags "engineering units exceeded".Widen the engineering-unit range if you need values outside it.Open
Tag browser shows unrounded doublesGateway adminThe tag browser shows floating-point values unrounded, for example 56.489999999999995.None needed. The live value is correct; only the display is unrounded.Open
Numeric component truncates text instead of shrinking itHMI runtimeA numeric component truncates text such as 28.1 A instead of shrinking the font to fit.Make the component wider, or shorten the text.Open
Open project dialog shows two identical buttons per projectControl Canvas designerThe Open project dialog shows two identical buttons for each project.Either button opens the project.Open
Time series chart history pens all draw in #222222HMI runtimeHistory pens on a time series chart all draw in #222222, so the traces are hard to tell apart.None.Open
Chart pen names use only the last tag path segmentHMI runtimeA chart pen is labelled with only the last segment of the tag path, so pens from different folders or instances can share a name.None, unless the chart has a field to rename the pen.Open
Small scrollbars on an HMI pageHMI runtimeScrollbars on an HMI page are small and hard to use.Resize the browser window, or scroll with the mouse wheel or a trackpad.Open
Whole struct variables cannot be forcedLogic/PLCA whole struct variable cannot be forced. Only its members can.Force the members one at a time.Open
Changing a mapping direction needs a redeployLogic/PLCChanging a tag mapping direction does not take effect until you compile and deploy again.Choose Compile and deploy after you change the direction.Open
Write once on a write-to-tag member is lost on the next scanLogic/PLCA write once on a write-to-tag member is lost on the next scan.None. A one-shot write does not hold past the next scan.Open
A write-to-tag member that is not forced writes 0Logic/PLCA write-to-tag member that is not forced writes 0.Force the member, or have the program write the value you want each scan.Open
Scalar program variables show no online valuesLogic/PLCScalar program variables, for example PeakGrp1, show no online values in the editor.Try the watch table. There is no inline value in the editor.Open
Keywords highlighted inside the second line of a multi-line commentLogic/PLCIn a multi-line comment, keywords on the second and later lines are still highlighted as code. Cosmetic only.None needed.Open
Force menu tooltip overlaps its titleLogic/PLCThe force menu tooltip overlaps the menu title. Cosmetic only.None needed. Move the pointer off the title.Open
No option to force a password change at first sign-inGateway adminAfter a restore or the first sign-in, ERIC does not require the user to change the password.Change the password yourself after you sign in.Open
Backup passphrase must be at least 12 charactersGateway adminA backup passphrase must be at least 12 characters. An empty passphrase is not allowed. The browser shows its native "Please lengthen this text" message.Use a passphrase of at least 12 characters.Open
