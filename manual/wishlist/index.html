Future features and wishlist

This is the wishlist. The same list is in the repository at docs/wishlist.md. How an item gets funded is on Funding and support.

Items the soft release does not include. Each line says what it is, why a plant would care, a rough effort, and the status. Effort is a size, not a date: small is a focused change, medium crosses a few modules, large is a new subsystem. Token cost is the same scale for anyone budgeting an agent to build it.

Nothing here is promised. How an item gets paid for is described in Funding and support. Paying funds that item's design, tests, and manual page. It does not buy a private fork of the name ERIC. You can also send a pull request instead of paying.

Deferred from 0.1.1-beta​

Found in the 0.1.1 new-user audit. None of them stops a fresh install from working; each has a workaround. Open product defects from this audit, and defects found later, are also listed on Known bugs (0.1.1-beta).

ItemWhy it mattersEffortStatus
PLC program resumes after a gateway restartA program that was running comes back stopped after a restart. Workaround: choose Compile and deploy again.SmallNot started
Drivers start at once after a backup restoreAfter a restore some devices and connections showed Not Started until the gateway restarted. A test at the current build did not reproduce it; confirm in the clean-machine audit. Workaround: restart the gateway after a restore.SmallNeeds a repro
Force values inside function block instances in online modeOnline mode forces mapped I/O only. Forcing a member of a function block instance (for example a timer input) needs engine support and a Logic editor control.MediumNot started
Show view updates the browser addressSwitching views leaves the old view in the address bar, so a reload or a shared link opens the wrong view.SmallNot started
History queries leave out empty minutesMinutes before recording started show as blank rows with 0 samples. They should be left out or marked as no data.SmallNot started
Stray "Diagnostics" word on UDT member rowsCosmetic: the UDT instance member list shows an extra label.SmallNot started
Reliable timing in two testsThe gateway EAM test under heavy load and one Control Canvas checkbox browser test sometimes fail on timing.SmallNot started
In-app gateway restartThe admin page had a Restart button, but a gateway started from the Linux archive launcher stopped and never came back, because nothing restarts it. It was removed; to restart, stop ERIC and start it again. A safe in-app restart needs a supervisor on every install type.MediumNot started
Browser test for the HMI reacting to a forced valueTest coverage: a forced PLC output should show on an HMI screen.SmallNot started

Funding and support​

The model is written for testers in Funding and support. These four pieces are planned for after the beta. Together they are about 20% of a week of agent time, inside a 15–25% band. None of them are built.

ItemWhy it mattersEffortStatus
Funding page and payment webhooksA wishlist issue needs a public progress bar and a way to take Stripe, GitHub Sponsors, and Open Collective payments against that goal.About 4% of a week of agent timePlanned, not built
Paid support assistantA customer buys credit, uploads logs or a project export, and gets a diagnosis from the manual and the source. It stops when the credit runs low and shows the running cost. Files stay private and are deleted after a retention period.About 10% of a week of agent timePlanned, not built
Automated bug filerWhen support finds a real defect, it opens a sanitized GitHub issue after the customer agrees, so the community can send a pull request or fund the fix.About 3% of a week of agent timePlanned, not built
Pull-request review automationA review checks safety and fit with the project before Nick Hepburn decides whether to merge. The CLA still applies.About 4% of a week of agent timePlanned, not built
