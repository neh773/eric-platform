## What this build is for

A bench. A trainer. A controller or instrument that can sit in a faulted state without hurting anyone and without damaging equipment you cannot afford to stop. A fictional project such as the Brownsville example, which does not talk to a plant.

## What this build is not for

- A live production process.
- Life safety: emergency stop, fire, gas detection, burner management, or anything a person relies on to get out of the way.
- Equipment protection: a trip that is the last thing between a machine and damage.
- A safety integrity function of any SIL.

The Windows soft-PLC is a normal Windows process. A banner stays on the Logic screen while it runs. That banner is separate from this warning. Windows does not give that process a real-time cycle.
